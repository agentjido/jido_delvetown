## Work Management

This project tracks work with `bw` (Beadwork). Beadwork persists plans,
progress, and decisions in Git, so they survive compaction, session boundaries,
and context loss.

Always run `bw prime` before you start work. It supplies workflow context,
current state, and repository hygiene warnings.

Committing, closing issues, and syncing are part of completing a task. They do
not need separate permission.
